## Scenario
A learner prints the first five multiples of a chosen number. The current sample values are already present in the Java file. Make the program produce the result required below.

## Task
At a food stall, the program is used for a short beginner exercise. Make it follow the stated rule for the supplied values. Keep the solution within basic Java syntax, variables, conditions, loops, arrays, strings, and simple methods.

## Expected output
```text
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
```

## Completion criteria
